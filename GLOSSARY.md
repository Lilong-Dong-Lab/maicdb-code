# MAIC-DB (maicdb-code)

The executable-schema and tooling repo for the Mechanically Activated Ion
Channel Database: formal schema, loader, query library, and the published
data artifacts. Its companion **vault** repo is the curation authority.

## Language

**Vault**:
The private companion repo (`Lilong-Dong-Lab/Project_DataBase_MAICDB`) that
is the curation and data authority: frozen corpus, scrape archives, project
records. It stays private even when this repo goes public.
_Avoid_: database repo, project repo

**Data artifact**:
The frozen, published file set built from a frozen corpus — `maicdb.sqlite`,
`maicdb.sql`, `load-manifest.json`. The citable object behind the dataset
DOI.
_Avoid_: database (ambiguous with the schema/code), dataset release

**Data release**:
A frozen corpus version published as a data artifact, named by a
`vX.Y.Z-data` tag in this repo and mirrored as a Zenodo dataset version
(e.g. `v1.0.0-data` → Zenodo version 1.0.0). The release unit of the data
axis; moves independently of the code version.
_Avoid_: release (ambiguous with code releases), drop

**Code version**:
The semver of the `maicdb` package in `pyproject.toml` — schema, loader,
query tooling. Moves independently of data releases.
_Avoid_: schema version (that is `schema_version` inside a data artifact)

**Concept DOI**:
The Zenodo DOI that always resolves to the latest data release. Cite this
for "MAIC-DB" generically.
_Avoid_: umbrella DOI, master DOI

**Version DOI**:
The Zenodo DOI pinned to one data release version. Cite this to make an
analysis reproducible against exact data.
_Avoid_: record DOI, per-release DOI

**Channel**:
The browsing and citation unit of the database — one mechanically activated
ion channel entity (12 in v1.0.0), named by its gene symbol and carrying
organism, UniProt accession, family, and ortholog group.
_Avoid_: gene (a gene symbol names a channel; it is not a separate entity)

**Family**:
The grouping of channels — 7 in v1.0.0 (e.g. PIEZO, K2P) — recorded as the
`family` attribute of a channel.
_Avoid_: channel family (older docs said "12 channel families"; that phrase
counted channels, not families)

**Gene symbol**:
The human-readable name of a channel (e.g. PIEZO1, TREK-1) — an identifying
attribute of a channel, not a standalone entity.
_Avoid_: gene (when it implies a separate table, page, or count axis)

**Census**:
A counted property of the frozen corpus, derived deterministically from a
data artifact — raw SQL over `maicdb.sqlite`, or a composition of the
analysis loaders. Census values live in one generated snapshot
(`tests/census_snapshot.json`, keyed by freeze tag); tests recompute and
compare against it.
_Avoid_: stat, expected value

**Pin**:
A frozen expected value a test asserts — the test-side record of a census
value at a freeze. Generated pins cite the snapshot and the generator
(`maicdb-census`); transcribed pins (scalar floats, accession ids) carry a
docstring derivation trail per `CODING_STANDARDS.md` §6.
_Avoid_: fixture number, snapshot (that is the file, not the value)

**Freeze manifest**:
The code-side pinned input contract for a load (`db/freeze-manifest.json`,
ADR-0007): freeze identity (tag, vault commit, declared freeze date, schema
version), a closed-set sha256 inventory of the frozen surface's git blob
bytes, and the conservation counts. Generated by
`scripts/write-freeze-manifest.py` at each retarget; the loader
hash-checks every load against it.
_Avoid_: manifest (ambiguous — see Load manifest), lockfile

**Load manifest**:
The loader's output record (`db/load-manifest.json`) — row counts,
disclosures, freeze point, and `freeze_manifest_sha256`, the chain link
back to the freeze manifest. Part of the published data artifact; the
vault's data notes name it the OFFICIAL COUNTS source.
_Avoid_: manifest, freeze manifest (that is the input contract)

**Frozen surface**:
The set of vault files a load treats as immutable: tracked files under
`data/` plus the literature-mining configs, excluding root schema docs
(`data/*.md`) and validator-state JSONs (`configs/*.json`). Inventoried
closed-set by the freeze manifest; any change requires a new vault tag
and a regenerated manifest.
_Avoid_: data (too broad — vault docs outside the surface churn legally)

**Frozen layers**:
The piezo1/piezo2 channel directories specifically, whose evidence quotes
are frozen-unverified by user decision (2026-08-27) and accept additive-only
modification — a QUOTE-STATE designation, distinct from the frozen surface
(all frozen files) and from a frozen corpus (a tagged release as a whole).
_Avoid_: frozen (unqualified — the word carries three senses; pick the
specific one)
