## 背景与动机

2021年诺贝尔生理学或医学奖授予了 **PIEZO 通道**的发现者，标志着机械传导研究进入黄金时代。该领域的文献呈指数级增长，不断揭示细胞如何感知和响应机械力。

然而，珍贵的定量数据碎片化地散布于数千篇研究论文中，单位、实验方案和报告标准的异质性造成了"巴别塔"困境。

**MAIC-DB** 旨在解决这一问题，建立集中化、标准化的资源，将基因身份、蛋白质生物物理特性和细胞力学有机联系起来。

## 项目目标

### 核心目标

构建一个专业数据库，收录现有生物信息学资源中缺失的机械激活离子通道**定量生物物理参数**。

### 关键交付成果

| 目标 | 描述 |
|------|------|
| **数据标准化** | 跨研究标准化异质的激活数据 |
| **知识整合** | 建立基因身份 → 蛋白质生物物理 → 细胞力学的关联 |
| **药物研发支持** | 为机械治疗药物开发提供结构化数据 |
| **临床解读** | 支持机械敏感基因的遗传变异解读 |

## 解决的问题

### 现有数据库提供的资源

| 资源 | 提供内容 |
|------|----------|
| IUPHAR/BPS Guide to Pharmacology | 基因命名、配体数据 |
| UniProt | 蛋白质序列 |
| PDB | 三维结构 |
| Channelpedia | 电生理数据 |
| MechanoBase | 组织/细胞力学特性 |

### 缺失的内容（MAIC-DB 的定位）

| 参数 | 描述 | 示例 |
|------|------|------|
| **P50/T50/X50** | 50% 激活所需的压力/张力/压痕 | 30 mmHg, 5 mN/m |
| **τ_act, τ_inact** | 激活和失活时间常数 | 2 ms, 50 ms |
| **电导** | 单通道电导 | 35 pS |
| **刺激参数** | 探针几何形状、速度、记录模式 | 膜片钳、细胞贴附式 |
| **压力-响应曲线** | 完整的剂量-响应关系 | Boltzmann 拟合参数 |

### 生物信息学中的"缺失环节"

```
基因序列  ────────►  蛋白质功能  ────────►  细胞力学
   ✓                    ✗                    ✓
              ↑
        MAIC-DB 填补这一空白
```

## 目标通道家族

| 家族 | 关键蛋白 | 机制 | 重要性 |
|------|----------|------|--------|
| **PIEZO** | PIEZO1, PIEZO2 | 脂质力传递 | 2021年诺贝尔奖；触觉、本体感觉、血管发育 |
| **TRP** | TRPV4, TRPA1, NOMPC | 多模态传感器 | 疼痛、温度、机械感知 |
| **K2P** | TREK-1, TREK-2, TRAAK | 脂质力传递 | 神经保护、麻醉靶点 |
| **OSCA/TMEM63** | OSCA1.1, TMEM63A/B | 脂质力传递 | 植物-动物保守；渗透感知 |
| **MscL/MscS** | 细菌通道 | 脂质力传递 | 生物物理"标准参考"；渗透保护 |
| **TMC1/2** | MET 复合物组分 | 丝状力传递 | 听觉机械传导 |
| **DEG/ENaC/ASIC** | MEC-4, ENaC, ASICs | 丝状力传递 | 触觉、酸感知、退化素 |

### 激活机制

- **脂质力传递（Force-from-Lipids, FFL）**：膜张力直接门控通道（PIEZO、MscL、K2P）
- **丝状力传递（Force-from-Filament, FFF）**：力通过细胞骨架/细胞外基质系链传递（TMC、NOMPC）
- **混合模型**：脂质和细胞骨架共同调控（TRPV4）

## 数据库架构

### 拟定架构模块

```
┌─────────────────────────────────────────────────────────────────┐
│                        MAIC-DB 架构                             │
├─────────────┬─────────────┬─────────────┬───────────────────────┤
│   身份识别   │   生物物理   │    药理学   │       疾病            │
├─────────────┼─────────────┼─────────────┼───────────────────────┤
│ 基因符号     │ P50/T50     │ 配体名称    │ 突变                  │
│ UniProt ID  │ 斜率 (k)    │ 配体类型    │ 表型                  │
│ PDB 链接    │ τ_act       │ IC50/EC50   │ 功能影响              │
│ 别名        │ τ_inact     │ Δ-P50       │ 临床意义              │
│ 组织表达    │ 电导        │ 参考文献    │ 参考文献              │
│ 参考文献    │ I-V 曲线    │             │                       │
└─────────────┴─────────────┴─────────────┴───────────────────────┘
```

### 关键数据字段

#### 身份识别模块
- 基因符号（HGNC）、UniProt ID、PDB ID
- 蛋白别名、直系同源物
- 组织表达模式
- 亚细胞定位

#### 生物物理模块
- 激活阈值（P50、T50、X50）
- Hill 斜率 / Boltzmann 参数
- 时间常数（τ_act、τ_inact）
- 单通道电导
- 离子选择性
- 电压依赖性（如有）

#### 药理学模块
- 激动剂和拮抗剂
- 小分子调节剂
- 肽类毒素
- 浓度-响应参数

#### 疾病模块
- 遗传变异（SNV、插入缺失）
- 相关表型
- 功能测定结果
- 临床解读

## MIMIC 标准

**机械诱导电流的最小信息标准（Minimum Information about a Mechanically Induced Current, MIMIC）**——拟定的机械生物学实验报告标准。

### 必需元数据

| 类别 | 参数 |
|------|------|
| **刺激** | 类型（压力、牵张、压痕）、速度、探针几何形状 |
| **记录** | 模式（细胞贴附式、内面向外式、全细胞式）、放大器、滤波设置 |
| **细胞背景** | 细胞类型、物种、传代数、异源表达系统 |
| **环境** | 温度、浴液、电极内液 |
| **分析** | 阈值标准、曲线拟合方法、样本量 |

### 标准化的意义

标准化元数据可支持：
- 跨研究比较
- 荟萃分析
- 可重复性评估
- 数据质量评分

## 治疗应用

MAIC-DB 支持**机械治疗药物**的开发：

| 应用领域 | 靶点 | 潜在影响 |
|----------|------|----------|
| **疼痛管理** | Piezo2 抑制剂 | 非阿片类神经性疼痛缓解 |
| **纤维化/癌症** | TRPV4/Piezo1 阻滞剂 | 阻断疾病进展 |
| **心血管** | Piezo1 调节剂 | 高血压、血管疾病 |
| **遗传性疾病** | 变异解读 | 遗传性干细胞增多症、淋巴发育不良 |
| **听力损失** | TMC1/2 变异 | 基因诊断、潜在治疗 |
